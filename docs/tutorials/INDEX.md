# Tutorials

Step‑by‑step guided learning.  Each tutorial builds on the previous one and
takes 5–10 minutes.

| # | Tutorial | What you get |
|---|---|---|
| 1 | [First calibration](01_first_calibration) | OpenCV stereo calibration, quality score, export back to OpenCV |
| 2 | [Improve with Ray2D](02_opencv_plus_ray2d) | Sub‑pixel corner refinement, lower reprojection error |
| 3 | [First central rayfield](03_first_central_rayfield) | 3‑D ray‑based model, triangulate a point |
| 4 | [First non‑central rayfield](04_first_noncentral_rayfield) | Per‑pixel ray origins, validate against synthetic ground truth |

After the tutorials, see the [How‑to guides](../how_to/INDEX) for task‑specific
recipes or the [Explanation pages](../explanation/INDEX) for the theory behind
the models.
