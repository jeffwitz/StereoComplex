── 5. WHY THE CMO MODEL CANNOT MATCH THE ZERNIKE RAYFIELD ──

  The CMO model (CMOPhysicalStereoModel) computes rays as:
    origin  = sub-pupil = (±b/2, 0, WD − f_obj + ε)
    direction = normalize( point_on_working_plane − sub_pupil )
    where point_on_working_plane = (WD·α_x, WD·α_y, WD)
    and α = undistort( (u−cx)·pixel_pitch / f_tube )

  This is a PURE PERSPECTIVE model:
    - All rays from one channel pass through a SINGLE point (the sub-pupil)
    - The direction field d(u,v) is ENTIRELY determined by the pixel-to-angle
      mapping α(u,v) = (u−cx)/f_tube * pixel_pitch
    - The only "free" variations come from 5 Brown-Conrady distortion coeffs
      applied to α before computing the ray

  The Zernike rayfield shows that the real microscope is NOT perspective:
    - d_y is NEARLY CONSTANT across the FOV (range 0.08, mean +0.06)
    - A perspective model predicts d_y ∝ (v−cy) → linear gradient (range 0.23)
    - The 3× range mismatch cannot be fixed by:
      * Moving the principal point (shifts the zero-crossing)
      * Adding distortion (only warps α, doesn't change the perspective structure)
      * Adding a telecentric offset ε (moves the sub-pupil Z, changes gradient
        magnitude but NOT the functional form d_y ∝ (v−cy))
      * Adding pitch/yaw rotations (rotate the entire bundle, don't change the
        perspective character)

  The optimizer's "solution" (f_obj=243, b=178, ε=−204) is a mathematical
  artifact: it pushes the sub-pupil 381 mm behind the sensor to make the rays
  as parallel as possible, then uses extreme distortion (±1.0, hitting bounds)
  and a shifted PP (2136,1638) to warp the angular mapping.  This "works"
  in the sense of reducing RMS from ~12 mm to 3.5 mm, but the parameters
  are physically meaningless.

── 6. WHAT WOULD BE NEEDED ──

  To model this microscope with a compact physical parameterization,
  the model needs to produce NEARLY PARALLEL rays (d ≈ constant across FOV)
  rather than perspective rays (d ∝ pixel position).

  Possible approaches:

  A. PER-PIXEL DIRECTION FIELD (already done by Zernike):
     d(u,v) = d_pinhole(u,v) + Σ a_m·Z_m(u,v)
     → 18 params per channel for order 2, captures real ray geometry
     → This is what StereoComplex already does

  B. TELECENTRIC CMO MODEL:
     Replace the perspective projection with an afocal/telecentric one.
     Instead of: ray = line from sub-pupil through point on working plane,
     Use: direction = optical axis + small per-pixel perturbation
     This would naturally produce nearly-constant d across the FOV.

  C. TWO-COMPONENT MODEL:
     A physically-motivated model with:
     - A perspective core (sub-pupil → chief ray)
     - A telecentric "shell" that makes peripheral rays more parallel
     - Parameterized by the "degree of telecentricity" (0 = perspective, 1 = telecentric)

  D. POLYNOMIAL DIRECTION MODEL:
     Directly fit a low-order polynomial to d_x(u,v) and d_y(u,v).
     This is what the Zernike d-field already does, but could be done with
     fewer parameters if restricted to physically meaningful basis functions
     (e.g., only radial terms for axisymmetric systems).

  The key insight: the real CMO microscope sits BETWEEN perspective and
  telecentric.  The Zernike rayfield captures this effortlessly.  A
  physical model needs to parameterize this "degree of telecentricity"
  explicitly.
