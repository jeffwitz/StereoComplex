# Figure — CMO rayfield interpretation in the X–Z plane

Standalone interpretation figure: it visualises the identified 26-parameter
CMO + per-arm SE(3) model as 3-D rays in the X–Z plane, intersected with the
effective sub-pupil plane and the object (working) plane, exposing the
baseline, working distance, and convergence angle the model implies.

**Manuscript status.** Not yet referenced by `paper/cmo/manuscript.tex`
(no `\includegraphics`). It is a ready, reproducible figure kept in compliance
with the *No orphan figures* rule so it can be inserted later without
rebuilding it from memory; the asset folder name keeps the placeholder `X`
until a manuscript figure number is assigned.

## Inputs

- `docs/assets/pycaso_real_data/intermediate_state.npz` — the versioned
  calibration state holding the identified 26p CMO + SE(3) parameters
  (shared input, same source as the other CMO figures).
- `labels.json` — the numerical values annotated on the figure (pupil/object
  Z planes, baseline, working distance, effective focal length, convergence
  angle, sampled pixel rows/columns). This file is **regenerated by the script**
  from `intermediate_state.npz`; it is a derived cache kept under version
  control so the annotated numbers are auditable without rerunning the model.

## Figure generation

```bash
rtk .venv/bin/python examples/notebooks/generate_fig_cmo_rayfield_xz.py
```

Outputs:

- `paper/cmo/figures/cmo_rayfield_xz.pdf` — vector figure.
- `paper/cmo/figures/cmo_rayfield_xz.png` — preview sibling.
- `docs/assets/cmo_paper/figureX_cmo_rayfield_xz/labels.json` — refreshed.
