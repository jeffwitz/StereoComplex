# Figure 9 (CMO paper) — dense specimen reconstruction

Editable source of truth for Figure 9 of `paper/cmo/manuscript.tex`
(line 654, `specimen_reconstruction.pdf`).

## Files

- `manifest.json` — paths to the three input data files, the ROI crop
  window, and the percentile clips used by the figure's colour scales.

## Upstream data (consumed by the figure)

- `docs/assets/pycaso_real_data/specimen_correspondences.npz` — DIS
  optical-flow pixel pairs (`uL, vL, uR, vR, image_size, roi`) generated
  by `examples/notebooks/10_pycaso_specimen_reconstruction.py`.
- `docs/assets/pycaso_real_data/specimen_reconstruction_cmo26.npz` —
  CMO 26p triangulation point cloud (`X, Y, Z, gap, valid`).
- `docs/assets/pycaso_real_data/specimen_reconstruction_zernike.npz` —
  Zernike rayfield triangulation point cloud (same keys).
- `paper/cmo/figures/specimen_left_with_roi.png` — annotated left image
  showing the ROI rectangle (static input asset; not regenerated by the
  figure script).

## Regenerate

```bash
rtk .venv/bin/python examples/notebooks/generate_fig_specimen_reconstruction.py
```

Outputs:

- `paper/cmo/figures/specimen_reconstruction.pdf` — used by
  `\includegraphics` in `manuscript.tex` (line 654).
- `paper/cmo/figures/specimen_reconstruction.png` — docs/preview
  counterpart.

## Re-running upstream

If the underlying point clouds need to be regenerated (e.g. after a
re-fit), rerun the specimen pipeline:

```bash
rtk .venv/bin/python examples/notebooks/10_pycaso_specimen_reconstruction.py
```

The figure regeneration above is then a single command.
